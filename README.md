# MOEXWatch

[![Свежая версия](https://img.shields.io/github/v/release/avertyu59-blip/MOEXWatch?include_prereleases&sort=semver&label=Свежая%20версия&color=blue)](https://github.com/avertyu59-blip/MOEXWatch/releases)
[![Скачать для Windows 10 x64](https://img.shields.io/badge/Скачать-Windows%2010%20x64-238636)](https://github.com/avertyu59-blip/MOEXWatch/releases)

Настольное приложение на C++20 / Win32 для наблюдения за акциями Московской биржи, ведения портфеля и анализа графиков.

## Скачать свежую версию

**[Открыть свежий выпуск и скачать готовый EXE →](https://github.com/avertyu59-blip/MOEXWatch/releases)**

Верхний выпуск в списке — самый новый. Скачайте его файл **MOEXWatch-<версия>-Windows-x64.zip**, распакуйте и запустите **MOEXWatch.exe**. Устанавливать Visual Studio, CMake или Build Tools для готовой сборки не требуется.

При обновлении закройте приложение и распакуйте новую сборку с заменой файлов в `D:\MOEXWatch`. Пользовательские данные хранятся отдельно в `%APPDATA%\MOEXWatch`; перед обновлением можно воспользоваться кнопкой «Резервная копия».

Индикатор версии вверху получает номер из GitHub Releases, включая **Pre-release**, и обновляется после публикации нового выпуска с учётом кэша сервиса. Все предыдущие версии остаются в [истории релизов](https://github.com/avertyu59-blip/MOEXWatch/releases).

## Возможности опубликованных сборок

- Свечные графики, RSI, SMA, ATR, объёмы и нормированное сравнение с IMOEX.
- Портфель: покупки и продажи, открытые позиции, средняя цена, прибыль и доли бумаг.
- Уровни средней цены, стоп-лосса и тейк-профита на графике.
- CSV-импорт с предварительным просмотром, проверкой ошибок и дубликатов; экспорт операций.
- Дивидендная аналитика и события с источниками и статусами.
- Технические и ценовые условия, уведомления Windows, история срабатываний.
- Сортировка таблиц, локальный кэш дневных свечей и резервные копии.
- Проверка правил на истории с комиссией и сравнением с IMOEX.

Данные могут поступать с задержкой. Уведомления проверяются, пока приложение открыто. Дивиденды пока не включены в прибыль портфеля и бэктест; полноценный налоговый и FIFO-учёт не реализован. Приложение не отправляет поручения брокеру.

## Проверка сборок

Перед публикацией готового EXE выполняются сборка MSVC x64 и CTest. Результаты доступны в [GitHub Actions](https://github.com/avertyu59-blip/MOEXWatch/actions). Полный визуальный проход на Windows 10 не заменяется автоматическими тестами.
