# MOEX Watch 0.5.1

C++20 / Win32 приложение для Windows 10 x64. Включает свечной график, технические индикаторы, блокнот закрытых сделок, настраиваемые сигналы и проверку стратегии на истории.

## Готовые сборки и история версий

Все опубликованные версии доступны в [GitHub Releases](https://github.com/avertyu59-blip/MOEXWatch/releases).
Для запуска скачайте **MOEXWatch-<версия>-Windows-x64.zip**, распакуйте его и запустите **MOEXWatch.exe**. В архив включены библиотеки MSVC; устанавливать Build Tools для готовой сборки не требуется.
Каждой версии соответствует отдельный тег и исходники. Предыдущие опубликованные выпуски сохраняются; файлы опубликованной версии автоматически не заменяются. Текущие выпуски помечаются как тестовые (Pre-release).

Автопубликация запускается при изменении `VERSION.txt` в `main` или текущей ветке разработки `feature/0.3.1-position-levels`, а также по тегу `v<версия>`. Перед публикацией выполняются сборка MSVC и CTest. Добавление новой версии не удаляет старые релизы.

## Обновление из исходников на вашем компьютере

Закройте MOEX Watch. Распакуйте архив прямо в `D:\MOEXWatch`, заменив исходники. Архив не содержит вложенной папки проекта и не содержит готового EXE.

В Developer Command Prompt for VS 2022 выполните:

```cmd
cd /d "D:\MOEXWatch"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ".\build_windows.ps1"
start "" "D:\MOEXWatch\MOEXWatch.exe"
```

Скрипт проверяет сборку и тесты, затем копирует EXE прямо в корень проекта. Исходный EXE также остаётся в `build\Release`. Нужны Build Tools / Visual Studio 2022 с C++ MSVC v143, Windows SDK и CMake.

## Рыночный контекст 0.4.0

- На графике отдельная панель сравнения акции и IMOEX с общей базой 100 от начала выбранного периода. Ряды сопоставляются по календарной дате; при отсутствии общей истории сравнение не рисуется.
- ATR(14) по сглаживанию Уайлдера показывается в рублях и как процент от последнего дневного закрытия. Это оценка типичного диапазона, не направление цены.
- Под свечами отображается гистограмма дневных объёмов. Если объём сессии превышает 2× среднее за 20 предыдущих сессий, столбец выделяется.
- История IMOEX загружается при нажатии «Обновить». Если загрузка не удалась, приложение сохраняет прежнюю историю, помечает её устаревшей и показывает причину.
- В панели аналитики дополнительно отображаются ATR(14) и его доля от цены.

## Графики на вкладках 0.5.1

- В основной аналитике и отдельном окне доступны вкладки «Цена», «Сравнение с IMOEX», «Объёмы», «RSI». Каждый график занимает всю область отрисовки.
- «Цена» сохраняет свечи, SMA20/50/200, ATR, уровни позиции и отметки дивидендных отсечек.
- В отдельном окне период графика выбирается независимо от основного; вкладки также переключаются независимо. Переключение не вызывает повторную загрузку данных.

## Дивидендная аналитика 0.5.0

- На вкладке «Аналитика» кнопка «Дивиденды» открывает отдельное окно с увеличенным графиком выбранной акции и историей доступных дивидендных событий.
- Отсечки отмечаются вертикальными линиями и маркерами на свечном графике.
- Таблица показывает дату отсечки, последнюю доступную торговую сессию перед ней, сумму на акцию, расчётную валовую доходность относительно закрытия этой сессии и статус записи.
- Данные загружаются отдельно по кнопке «Обновить события» из MOEX ISS; приложение показывает URL источника, дату проверки и сохраняет последний успешный набор в памяти до закрытия программы.
- Ответ ISS может быть неполным. Если будущая запись присутствует, её статус всё равно обозначен как требующий проверки. Рекомендации и утверждения эмитента, календарь выплат и налоги здесь пока не моделируются; для решения о праве на выплату сверяйтесь с официальным сообщением эмитента.
- Дивидендный доход пока не включён в портфель и бэктест. Даты покупки и доходность отображаются только при наличии подходящей дневной свечи до отсечки; доходность указана до налогов.

- Список сделок и сводные итоги сохраняются отдельно в `%APPDATA%\MOEXWatch\trades.csv`.
- Для десятичных чисел можно вводить точку или запятую. Пустые комиссия и ставка налога трактуются как 0; ставки налога принимаются от 0 до 100%.
- Кнопка целевой цены переименована в «Сохранить цель», чтобы текст помещался целиком.
- Вкладка «Сигналы»: включаемые условия RSI ниже/выше заданного уровня, цена выше SMA200 и близость к цели в настраиваемом диапазоне.
- Режим совпадения «Любое условие» или «Все условия»; список показывает тикер и конкретные причины совпадения.
- Уведомление Windows появляется при переходе бумаги из состояния без совпадения в состояние с совпадением; первый успешный запуск/обновление задаёт исходный уровень и не рассылает пачку уведомлений. Уведомления можно отключить.
- Автопроверка сигналов раз в 15, 30 или 60 минут; по умолчанию — 15 минут. Работает только пока приложение открыто, отключается на вкладке «Сигналы». Кнопка ручного обновления доступна на всех вкладках.
- Пороги, способ совпадения, уведомления и интервал автопроверки сохраняются в `%APPDATA%\MOEXWatch\signals.ini`.

- Вкладка «Тест стратегии»: прогон текущих правил вкладки «Сигналы» на истории выбранной акции и сравнение с удержанием IMOEX.
- Начальный капитал и комиссия на одну сторону сделки настраиваются. Комиссия применяется отдельно при каждой покупке/продаже стратегии и при входе/выходе из индекса.
- Результаты показывают период, конечную стоимость, доходность, количество завершённых сделок и максимальную просадку стратегии.

- Операции сохраняются отдельно от прежнего журнала закрытых сделок в `%APPDATA%\MOEXWatch\portfolio_transactions.csv`. Тикер открытой позиции нельзя удалить из списка наблюдения.

Для выбранной открытой позиции можно задать стоп-лосс и тейк-профит. Уровни отображаются в таблице портфеля и горизонтальными линиями на графике вместе со средней ценой входа. При усреднении уровни сохраняются; после полного закрытия не переносятся на новую позицию по тому же тикеру. Уровни только визуальные: приложение не отправляет сделки и не следит за срабатыванием стопов в фоне.

## Портфель и метод расчёта

Покупка увеличивает остаток и среднюю себестоимость. Комиссия покупки включается в себестоимость: новая средняя цена равна (прежняя себестоимость + цена и комиссия новой покупки) / новый остаток акций. Продажа уменьшает остаток по средней цене; зафиксированная прибыль равна количество продажи × (цена продажи − средняя цена) − комиссия продажи. Частичная продажа оставляет среднюю цену неизменной. Бумажная прибыль оценивается как текущая рыночная стоимость оставшихся акций минус их себестоимость с учётом комиссий покупки; будущая комиссия продажи и налог не включены. Если котировка отсутствует, позиция остаётся в таблице без оценки стоимости и бумажной прибыли. Звёздочка отмечает устаревшую последнюю котировку.

Даты операций вводятся в формате `ГГГГ-ММ-ДД`. Операции сортируются по дате; при совпадении даты порядок добавления сохраняется. Налоговые годовые базы в версии 0.3 не рассчитываются. Старый журнал закрытых сделок остаётся в `trades.csv` отдельно и не смешивается с портфелем.

## Проверка стратегии

Правила оцениваются только по дневному закрытию. Покупка или продажа выполняется по открытию следующей общей торговой сессии для акции и IMOEX. Если позиция открыта в конце периода, она закрывается по последнему доступному закрытию. Расчёт использует дробные условные акции и полный капитал; налоги, проскальзывание, спред, лоты и дивиденды не моделируются. IMOEX — индекс цен, а не доходность конкретного инвестируемого фонда. Прошлый результат не подтверждает будущую доходность; тест нужен для изучения поведения правила, не является рекомендацией.

## Сигналы

Порог RSI задаётся от 0 до 100; правило «ниже» использует строгое `<`, «выше» — строгое `>`. Условие SMA200 — цена выше среднего за 200 дневных свечей. Близость к цели означает отклонение от целевой цены не больше заданного процента. В режиме «Все условия» каждая включённая проверка должна быть доступна и истинна; в режиме «Любое условие» достаточно одного совпадения. Сигналы скрываются при устаревшей котировке или истории и являются наблюдениями по прошлым/текущим данным, а не рекомендацией совершить сделку.

Пока приложение открыто, данные перепроверяются через выбранный интервал или по кнопке «Обновить». Уведомление отправляется при появлении нового совпадения после установленного базового состояния; постоянное совпадение не вызывает повторное уведомление при каждом обновлении.

## Расчёт сделок

Валовая прибыль = (цена продажи − цена покупки) × количество. Результат после комиссии = валовая прибыль − введённая общая комиссия. Оценка налога = положительная часть результата после комиссии × введённая ставка налога. Чистая прибыль = результат после комиссии − оценка налога. При убытке расчётный налог по этой сделке равен нулю.

Ставку налога пользователь вводит сам для каждой сделки; пустое поле означает 0%, то есть расчёт без налога. Это упрощённый ориентир, а не налоговый расчёт: он не учитывает налоговый статус, годовую совокупную базу, перенос убытков, льготы, дивиденды и прочие правила. Комиссия указывается общей суммой по покупке и продаже. В журнал вносятся закрытые сделки; приложение не ведёт FIFO-учёт отдельных лотов и не отправляет поручения брокеру.

## Расчёты и ограничения

RSI: первые средние роста/падения рассчитываются по первым 14 изменениям закрытия; следующие — `(13 * предыдущее среднее + текущее изменение) / 14`. Нулевая средняя потеря при росте даёт RSI 100, полностью неизменные цены — 50. ATR(14): истинный диапазон — максимум из `high-low`, `|high-предыдущее close|` и `|low-предыдущее close|`; первый ATR — среднее за 14 свечей, затем используется сглаживание Уайлдера. Объём сравнивается со средним 20 предшествующих дневных свечей; текущий день не входит в базу. Сравнение акции и IMOEX нормируется к 100 по первой общей дате выбранного диапазона. SMA — обычная средняя за соответствующее число свечей. Индикаторы считаются по всей загруженной истории, затем график обрезается до выбранного периода.

Фильтры по RSI и SMA исключают устаревшие котировки и историю. Фильтр целевой цены требует свежей котировки. Уровни RSI не являются рекомендацией купить или продать. Последняя дневная свеча может быть незавершённой; объём и RSI до закрытия сессии могут меняться. Приложение не делает собственную корректировку цен на дивиденды/сплиты и не отправляет сделки. Данные публичного ISS могут задерживаться, доступность отдельных блоков зависит от MOEX.

Формула сглаживания: https://www.fidelity.com/bin-public/060_www_fidelity_com/documents/learning-center/trading-with-momentum-transcript.pdf

## Проверка

Portable C++ тесты проверяют CSV MOEX, RSI Уайлдера на контрольной последовательности, ATR Уайлдера, SMA50/200, нормирование и выравнивание сравнения по датам, расчёт отношения объёмов к предыдущим 20 сессиям, фильтры, расчёты сделок и режимы сигналов «любое/все», объяснения совпадений, устаревшие данные, некорректные пороги, портфель: средневзвешенная цена, комиссии покупок и продаж, частичная продажа, зафиксированная и бумажная прибыль, неверные даты и нехватка акций; бэктест: отсутствие заглядывания в следующий close, комиссии обеих сторон, сравнение с IMOEX и проверка пересечения дат. На Windows скрипт запускает эти же тесты через CTest. Workflow GitHub Actions собирает Win32-приложение с MSVC на Windows Server 2022 и запускает CTest при push и pull request. Визуальную работу интерфейса нужно отдельно проверить на Windows 10.
