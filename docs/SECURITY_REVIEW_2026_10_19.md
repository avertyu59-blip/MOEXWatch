# Проверка безопасности — 19 октября 2026

Область: WinHTTP, диагностические журналы, CSV-экспорт, открытие ссылок,
права GitHub Actions. Это целевая проверка исходников, не полный аудит.

## Изменения

- WinHTTP не следует перенаправлениям автоматически. HTTP 3xx возвращается
  вызывающему коду и отклоняется без повторных попыток. Если провайдер сменит
  адрес, потребуется проверить и обновить исходный URL; старый кэш сохраняется.
- Диагностика отказывается писать при обнаружении файловой символической
  ссылки или нестандартного файла на месте журнала и двух файлов ротации.
- Для сборочных workflows Windows и Qt явно заданы права `contents: read`.
  Публикация релиза сохраняет отдельное необходимое право записи.
- Исправлена обработка повреждённого периода графика и повторного открытия
  настроек; добавлены регрессионные проверки.

## Подтверждено по коду

- TLS-проверки WinHTTP не отключены; понижение HTTPS до HTTP исключено
  запретом перенаправлений. HTTP разрешён только для локального тестового узла.
- Ответ ограничен 2 МБ, запрос — сроком 20 секунд; повторов не более трёх.
- Сетевой журнал содержит числовые коды, этап и обозначение источника;
  адрес запроса, тело ответа и операции портфеля туда не передаются.
- CSV ограничен 4 МБ и 10 000 операций; запись импорта требует предпросмотра.
- CSV-экспорт проверяет канонический путь и запрещает запись внутри профиля.
- Открытие источника в браузере допускает HTTPS без имени пользователя/пароля.

## Оставшиеся ограничения

- Проверки пути перед записью не исключают подмену другим процессом между
  проверкой и открытием. Полной защиты от процесса с правами пользователя нет.
  Проверка журнала не запрещает ссылки в родительских каталогах.
- Windows junction покрыты новыми нативными тестами CSV и JSON экспорта:
  создание нового файла и попытка замены существующего через alias профиля.
  Другие типы reparse points и подмена пути во время записи не покрыты.
- Все 15 прямых ссылок на семь GitHub Actions закреплены SHA коммитов,
  полученными из репозиториев поставщиков. Это не аудит их транзитивных
  зависимостей и скачиваемых ими инструментов.
- Подготовлен Authenticode-процесс с обязательной проверкой доверия и метки
  времени (`WINDOWS_SIGNING.md`). Фактическая подпись EXE не выполнена:
  доступный сертификат издателя не подтверждён.
- Нет гарантии шифрования файлов профиля; права доступа и шифрование диска
  определяются настройками Windows пользователя.
- Отмена CSV пока не прерывает сам парсер; повторный запуск может ожидать
  завершения предыдущего потока в UI.

## Проверки

Добавлены: отказ следовать 302 в Windows loopback-тесте; отсутствие повторов
для 302; запрет записи через файловые symlink в диагностике на POSIX;
повреждённые настройки периода и сброс состояния при смене файла настроек.
Windows-тест требует нативного запуска и не считается выполненным на Linux.

Локальная полная сборка Qt 6.8.3/GCC завершилась успешно. CTest: 32 из 32
наборов прошли, включая тесты диагностики, файлового хранения, CSV-импорта,
экспорта и QML smoke. Новая ветка WinHTTP с запретом перенаправления на Linux
не компилируется и требует Windows CI перед включением в релиз. Windows
проверки junction, WinHTTP и PowerShell запущены в PR №13; результат нужно
проверять по завершённым задачам CI этого PR, а не по локальному CTest.
