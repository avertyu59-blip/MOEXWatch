# Отчётность компаний

`fundamentals_v1.json`: JSON `{ "version": 1, "records": [...] }`. Импорт сначала проверяется и показывается; применение объединяет записи по тикеру, совпадающие заменяет. Экспорт сохраняет исходные поля. Повреждение или неизвестная версия блокирует запись, исходный файл не изменяется.

Обязательные строковые поля: ticker (A–Z, 0–9), company, sector, standard (IFRS/RAS), period (одинаковый для сравнимых отчётов, например 2025), currency RUB, unit million, sourceUrl HTTPS, publicationDate и checkedDate ISO YYYY-MM-DD. durationMonths: 3/6/9/12; YYYY-Qn требует 3, YYYY-Hn — 6, YYYY-9M — 9, YYYY или YYYY-FY — 12 месяцев. Модули чисел ограничены 10^18. Отрицательный equity допускается; P/B при equity <= 0 отсутствует.

Числовые поля, допускающие null/отсутствие: revenue, netProfit, ebitda, cfo, capex, debt, cash, equity — млн рублей; shares — фактическое число акций в штуках; dividendPerShare — рублей на акцию. Неизвестное число не заменять нулём. Для банков sector содержит «Банки» или Bank. Данные вводятся из проверенного отчёта; автоматическая загрузка не обещается.

FCF = CFO − capex; чистый долг = debt − cash. P/E и EV/EBITDA только по 12-месячной отчётности и положительному знаменателю. Банкам не рассчитываются долговые мультипликаторы. Рыночная капитализация использует последнюю доступную цену, не гарантирующую свежесть. Старше 90 дней с проверки — пометка об обновлении. Упрощённые формулы требуют интерпретации и не являются рекомендацией.
