# MOEXWatch 0.7.2 — C++ / Qt Quick

Распакуйте весь ZIP и откройте MOEXWatch-Qt.exe. Qt, Visual Studio и CMake для готового приложения не нужны. Classic включён для прежних функций, включая CSV-импорт операций.

Закройте предыдущие копии перед обновлением. Qt и Classic версии0.7 используют общую неблокирующую защиту профиля; старые EXE0.6 не участвуют в ней. Данные и существующие ID/журнал сохранены в APPDATA/MOEXWatch. Кнопка резервирования копирует журнал, наблюдения, правила/историю, дивиденды, дневник, фундаментальные данные, корпоративный календарь и настройки окна. При повреждении пользовательского файла соответствующий модуль блокирует перезапись.

## Рабочие вкладки

- Обзор: свечи/SMA/RSI/объёмы/ATR, сравнение с IMOEX по общей дате, уровни позиции по UUID. Колесо/+− масштаб, drag/стрелки сдвиг, Home сброс, hover OHLC.
- Скринер наблюдаемых бумаг: RSI/SMA200/цель/объём/ATR, объяснения и числовая сортировка.
- Сигналы: настройки условий и ценовые пороги, история переходов, уведомления и автообновление15/30/60 минут. Первый снимок и устаревшая котировка не создают уведомлений. Приложение должно оставаться открытым.
- План покупки: размер лота вводится явно; целые лоты ограничены бюджетом с комиссией и допустимым убытком. Это расчёт сценария без плеча, не заявка брокеру; гэп может увеличить убыток.
- Компания/сравнение: ввод из отчёта или JSON-импорт с предпросмотром и HTTPS-источником; единицы — млн₽, акции в штуках. Пропуски не заменяются нулём. Годовые и отраслевые ограничения коэффициентов обозначены. Приложение проверяет формат, а не достоверность отчёта. Автоматической загрузки официальной отчётности нет.
- События: автоматическая загрузка дивидендов из открытых источников, статус/сверка отдельно, кэш и отмена. Отчётности/собрания добавляет пользователь по источнику. Прогноз не является фактическим поступлением.
- Стратегия: выбранная бумага, капитал/комиссия/даты/правила, расчёт в фоне. Исполнение на открытии следующей общей даты акции и индекса; индикаторы используют историю акции, пропуски индекса её не меняют. Выбранное начало запускает прогрев заново. Текущая цель применяется ретроспективно как сценарий. Модель допускает дробное количество и ценовой IMOEX; налог, дивиденды, лоты, проскальзывание и внутридневные стопы не учитываются.
- Портфель/операции: стоимость, доли и прибыль до налога, ввод покупок/продаж, подтверждение удаления и уровни текущей позиции.
- Дневник: расчётные идеи отдельно от реальных операций, причины, статусы, редактирование и удаление с подтверждением.

Настройки: светлая/тёмная тема, бумага/период/сравнение, активная страница, нормальные размеры и положение окна. Окно ограничивается доступным экраном при восстановлении. Шапка страницы поддерживает перетаскивание, справа есть кнопки управления окном, Ctrl+Q закрывает приложение. Системная рамка учитывается при восстановлении положения. Ctrl+R обновляет рынок; Ctrl+1/2/3 — обзор/скринер/сигналы.

Только явный --demo показывает синтетические операции/историю, временный профиль и запрет записи; реальные дивидендные события в demo не подмешиваются. Обычный запуск не генерирует финансовые показатели. Сетевой адаптер этой сборки работает в Windows; Linux используется для проверки UI и переносимых модулей.

Сборка: Qt6.8.3, MSVC2022x64, CMake>=3.20; powershell -File build_qt_windows.ps1 -QtRoot C:\Qt\6.8.3\msvc2022_64. Динамическая линковка Qt; лицензии и сведения — QT_THIRD_PARTY.md и licenses/.

CTest проверяет ядро, хранение/ID/миграции, межпроцессную блокировку, контроллеры и реальный QML smoke всех страниц. Пакет запускается без SDK в PATH до архивации и после распаковки ZIP. Автоматические проверки не заменяют нативную ручную проверку Windows10, GPU, нескольких мониторов и экранного диктора.
